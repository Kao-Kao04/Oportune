# Google Stitch Prompts — UI/UX

Copy-paste prompts for designing the Student Opportunity Hub in [Google Stitch](https://stitch.withgoogle.com/).

## How to use

1. Create **one Stitch project** in **Mobile** mode. Keep every student screen in the same project so the style stays consistent.
2. Paste **Prompt 0 (Master)** first. It sets the look, the navigation, and the first screen.
3. Then paste the **screen prompts one at a time**, in order. Each one says which screens it links to.
4. If a screen comes out looking generic, use the **fix-up prompts** at the end, one change at a time.
5. Make the admin screens (Prompt 12) in a separate **Web/Desktop** project.
6. To connect the screens into a clickable prototype, use Stitch's prototype/linking feature if your version has it. Otherwise export to Figma and link the screens there, following the **Navigation map** below.

"Oportune" is a working name. Replace it everywhere if you choose a different one.

## Navigation map

```
Bottom nav (on every student screen): Browse · Saved · Me

Browse ──tap listing──▶ Opportunity detail ──Save (logged out)──▶ Sign-in sheet ──▶ Quick profile ──▶ back to detail (saved)
   │                        │                                                                       └─▶ Notification prompt (after 1st save)
   ├─search icon─▶ Search & filters sheet                       ├─Share──▶ phone share sheet (link preview)
   └─Closing soon / All / For you tabs                          ├─Report──▶ Report sheet
                                                                └─Apply on official site──▶ external link
Saved ──tap item──▶ Opportunity detail
Me ──▶ Edit profile · Reminder settings · Privacy · Delete account
```

## Prompt 0 — Master (paste first)

```
Design a mobile app called "Oportune" for college students in the Philippines. It helps them find real opportunities (scholarships, internships, hackathons, cybersecurity CTFs, free courses), share them to group chats, save them, and get reminded before deadlines. It is free.

The look should feel like a well-made, trustworthy public bulletin board or a good transit timetable. Calm, clear, information-first. It should look made by a careful human designer, not generated by AI.

Visual style:
- Background warm off-white paper (#FAF8F3), text near-black ink (#1C1B19), secondary text warm gray (#6B675F).
- One accent color: deep teal (#0F5257) for buttons and links.
- Deadline colors used sparingly: red (#B3261E) only for "closes in 3 days or less", amber (#9A6700) for "this week".
- Official-site badge: small green (#2E6B3F) label with a check, reading "Official .gov.ph" or "Official .edu.ph".
- Font: Public Sans for everything. Use tabular numbers for dates.
- Thin 1px dividers between list rows instead of floating cards. Small corner radius (6px). No shadows except on bottom sheets.
- No gradients, no glassmorphism, no glowing effects, no sparkle or AI icons, no 3D illustrations, no stock photos of smiling students, no emojis in the UI.
- Simple line icons (like Material Symbols Outlined), used only where they help.

Navigation: a bottom navigation bar with 3 tabs — Browse, Saved, Me — on every main screen. A top bar with the app name on the left and a search icon on the right.

First screen — Browse (user is not logged in):
- Three text tabs under the top bar: "Closing soon" (selected), "All", "For you".
- A horizontally scrolling row of category chips: All, Scholarships, Internships, Hackathons, CTFs, Courses, Events.
- A list of opportunities. Each row shows: deadline on the left in a narrow column (e.g., "Oct 31" with "8 days left" under it), then title (bold), organization, a category label, and the official badge if it applies. A small bookmark icon on the right.
- Use these real listings:
  1. "Undergraduate Thesis Grant in Natural Products" — DOST-PCHRD — Research grant — Oct 31 — Official .gov.ph
  2. "HKCERT CTF 2026 Qualifying Round" — HKCERT — CTF — Nov 4
  3. "Graduate Talent Program – Global Banking" — UBS — Graduate program — Nov 4
  4. "NASA Space Apps Challenge 2026" — NASA — Hackathon — Nov 14
  5. "Graduate Development Program (E-commerce)" — TikTok Shop — Graduate program — Nov 30
  6. "Students' Training Support Program" — DA-NFRDI — Internship — Dec 1 — Official .gov.ph
- Copy is plain and short, like a student wrote it. No marketing slogans.
```

## Fix-up prompts (if it looks too "AI")

Use one at a time on the screen that needs it:

- "Remove all gradients, glows, and shadows except on bottom sheets. Use flat off-white backgrounds."
- "Replace the cards with a simple list separated by thin 1px dividers, like a printed bulletin board."
- "Remove the illustration and decorative icons. Let the text and dates carry the design."
- "Rewrite the headline and buttons in plain, short words a Filipino college student would use. No slogans."
- "Make the deadline column the strongest visual element in each row, using tabular numbers."
- "Use only one accent color (#0F5257). Remove any purple, blue, or multi-color accents."
- "Reduce the corner radius to 6px and tighten the spacing so more listings fit on screen without feeling cramped."
- "Left-align the content; avoid centered hero layouts."

## What to avoid (why it looks like "AI slop")

- Purple/blue gradients, glassmorphism, glowing buttons, sparkle ✨ icons
- Big hero sections with slogans like "Unlock your future"
- Floating rounded cards with heavy shadows for every item
- Generic 3D or stock illustrations of students with laptops
- Emojis in buttons and headings
- Placeholder text like "Lorem ipsum" or "Opportunity Title 1". Use the real listings from `data/opportunities.csv`
